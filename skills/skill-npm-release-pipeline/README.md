# skill-npm-release-pipeline

Skill local para revisar y ejecutar un pipeline ordenado de release para paquetes npm tipo CLI.

## Alcance

- Validacion tecnica previa a release
- Inspeccion de `npm pack`
- Prueba del tarball en entorno externo
- Publicacion en npm
- Verificacion con `npx`
- Push, tag y release en GitHub

## Archivos

- `skill.md`: checklist operativo completo
- `examples.md`: prompts de ejemplo para escenarios de release
