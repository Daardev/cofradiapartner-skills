# Apple UI Skill

Esta skill orienta la generacion de interfaces con una direccion visual premium, limpia y moderna.

## Principios

- Jerarquia visual clara con bloques bien diferenciados.
- Espaciado amplio y ritmo consistente entre secciones.
- Tipografia limpia con escalas legibles en desktop y mobile.
- Grillas responsivas con enfoque mobile-first.
- Cards suaves, bordes redondeados y sombras sutiles.
- Microinteracciones utiles, discretas y orientadas a feedback.
- Fondos neutros y contraste correcto para accesibilidad.
- Composicion equilibrada y enfoque en claridad de contenido.

## Restricciones

- No copiar marcas registradas ni identidad visual exacta.
- No replicar textos protegidos o assets propietarios.
- Mantener inspiracion conceptual sin clonar sistemas cerrados.
