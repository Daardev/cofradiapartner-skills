# Apple UI Skill

Esta skill orienta la generacion de interfaces con una direccion visual premium, limpia y moderna, inspirada en los principios de Apple Human Interface Guidelines.

## Cuando usar esta skill

Invoca esta skill cuando necesites:
- Crear interfaces desde cero con estetica premium
- Mejorar designs existentes hacia un estilo mas limpio
- Disenar componentes especificos (cards, botones, formularios, navegacion)
- Construir paginas completas (landing, dashboard, producto, FAQ)
- Establecer un sistema de diseno coherente

## Principios de Diseno

### Jerarquia Visual Clara
- Cada seccion debe tener un proposito claramente identificable
- Usar un maximo de 2-3 niveles de tamano de texto por pantalla
- El contenido principal debe destacarse visualmente del secundario
- Evitar competencia visual entre elementos

### Espaciado y Ritmo
- Usar multiples de 8px para margenes y paddings (8, 16, 24, 32, 48, 64)
- Mantener consistencia vertical entre secciones
- El espacio negativo es tan importante como el contenido

### Tipografia
- Usar una familia tipografica limpia y legible (Inter, SF Pro, system-ui)
- Escala tipografica coherente: 34-48px display, 22-28px heading, 16-17px body
- Line-height: 1.4-1.6 para body, 1.2-1.3 para titulos

### Colores Sistema Apple
- Fondo principal: #FFFFFF (claro) / #000000 (oscuro)
- Fondo secundario: #F5F5F7
- Texto primario: #1D1D1F
- Acento: #0071E3 (azul Apple)
- Estados: #34C759 (success), #FF9500 (warning), #FF3B30 (error)

### Cards y Contenedores
- Border-radius: 12-20px para cards, 8-10px para botones
- Sombras sutiles: 0 2px 8px rgba(0,0,0,0.08)
- Padding interno: 16-24px

### Microinteracciones
- Duracion: 200-300ms para transiciones, 400-600ms para complejas
- Easing: ease-out para entrada, ease-in para salida

## Antipatrones

### NO HACER
- Usar gradientes complejos o fondos con patrones
- Mezclar mas de 2 familias tipograficas
- Usar colores saturados para fondos o texto principal
- Animaciones que distraen
- TEXTOS TODO MAYUSCULAS en cuerpo

## Restricciones
- No copiar marcas registradas de Apple
- No replicar textos protegidos o assets propietarios
- Mantener inspiracion conceptual sin clonar sistemas cerrados
